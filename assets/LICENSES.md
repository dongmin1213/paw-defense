### 포함된 에셋 팩:

#### 1. Platformer Assets Pixel (900 assets)
- **위치**: `images/sprites/kenney_platformer_pixel.png`
- **내용**: 픽셀아트 캐릭터, 적, 아이템, 타일, 배경
- **용도**: 게임 스프라이트 (캐릭터, 적, 아이템)

#### 2. RPG Pack (230 assets)
- **위치**: `images/tiles/`
- **내용**: RPG 타일셋 (건물, 지형, 나무, 문, 창문, 지붕)
- **용도**: 성벽/환경 타일, 배경

#### 3. UI Pack - Adventure Pack + Base Pack (220 assets)
- **위치**: `images/ui/`
- **내용**: 버튼, 패널, 진행 바, 아이콘, 체크마크, 코인, 커서, 화살표
- **용도**: 게임 UI 요소

#### 4. RPG Sounds (50 sounds)
- **위치**: `audio/sfx/` (hit, merge, buy, coins 등)
- **내용**: 칼 소리, 금속 소리, 동전, 도끼, 무기 등
- **용도**: 전투/거래 효과음

#### 5. UI Sounds (50 sounds)
- **위치**: `audio/sfx/` (tap, click, switch)
- **내용**: 클릭, 롤오버, 스위치 사운드
- **용도**: UI 조작 효과음

#### 6. Digital Sounds (60 sounds)
- **위치**: `audio/sfx/` (wave_clear, boss_kill, reward, game_over)
- **내용**: 파워업, 레이저, 전자음
- **용도**: 웨이브 클리어, 보스 처치, 보상, 게임오버 효과음

#### 7. Jingle Sounds - NES (17 sounds)
- **위치**: `audio/jingles/`
- **내용**: NES 스타일 짧은 배경음악/징글
- **용도**: 웨이브 시작/끝, 승리/패배 징글
