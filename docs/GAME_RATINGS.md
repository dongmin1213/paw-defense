# Paw Defense — 영역별 평가 (10점 만점)

## 1. 게임 디자인 / 시스템 설계 — 9 / 10

**강점:**
- 3축 적 스케일링 (HP, 수량, 속도)이 유닛 배치에 전략적 딜레마 부여
- 9개 독립 진행 루프 (웨이브/런/메타/승천/일일/해금/도감/발견/카드)
- 머지 → 유닛 수 감소 → 적 약화라는 고유한 전략 공식
- 반방치(Semi-Idle) + 로그라이트 + 머지의 3장르 융합이 잘 작동

**아쉬운 점:**
- 승천(Ascension) 시스템은 설계만 있고 구현 깊이가 아직 얕음

---

## 3. 밸런스 설계 — 9 / 10

**강점:**
- `balance_config.dart` 단일 파일 관리 (50+ 상수)
- 적 HP: `base × 1.08^wave × (1 + unitCount × 0.12)` — 다축 공식
- 유닛 ATK: `base × 2^(level-1)` — 머지 보상이 체감됨
- 유물 트레이드오프 설계 (전쟁의 신: ATK 3배 / HP -50%)
- 경제 이중 스케일링 (구매 횟수 1.15× + 보유 수 +3골드)

**아쉬운 점:**
- 후반(40웨이브+) 밸런스는 플레이테스트 데이터 없이 이론치만 존재

---

## 4. 코드 아키텍처 — 9 / 10

**강점:**
- 데이터(`data/`) / 로직(`systems/`) / 렌더(`renderers/`) / UI(`ui/`) 명확 분리
- 새 유닛/적/유물 추가 시 데이터 파일만 수정하면 되는 확장성
- Manager 패턴 일관 적용 (WaveManager, MergeManager, RelicManager 등)
- 12개 오버레이 구조로 Flutter ↔ Flame 통합 깔끔

**아쉬운 점:**
- `defense_game.dart`에 책임이 다소 집중되어 있을 수 있음

---

## 5. UI / UX 디자인 — 8 / 10

**강점:**
- `GameTheme` 통합 디자인 시스템 (색상 팔레트, 타이포, 간격, 공용 위젯)
- 5단계 희귀도 색상 체계
- 8단계 튜토리얼로 온보딩 체계적
- 머지 힌트(초록 글로우), 하이브리드 힌트(보라 글로우 + 🧬) 등 시각 피드백

**아쉬운 점:**
- 픽셀아트 폰트(Press Start 2P)와 한글 호환성 문제 가능성
- 화면 정보량이 많아 400x700 세로 화면에서 혼잡할 수 있음

---

## 6. 게임 필(Game Feel) — 8 / 10

**강점:**
- 히트스탑, 슬로모션, 줌펀치 (`defense_game_feel.dart`)
- 콤보 5단계 티어별 색상 + 화면 플래시
- 데미지 넘버, 파티클 이펙트
- 배속(1x/2x) 토글

**아쉬운 점:**
- BGM 1곡만 존재, 다이나믹/적응형 오디오 미구현
- 햅틱 피드백 미구현 (모바일에서 중요한 요소)

---

## 7. 리플레이 가치 — 9 / 10

**강점:**
- 16개 독립 변수가 매 런마다 다른 경험 제공
- C(58,7) = 수십억 가지 유물 조합
- 일일 챌린지 (날짜 해시 기반, 5천만+ 고유 시드)
- 도감 수집 (48유닛 + 10적 + 58유물)
- 점진적 시스템 해금으로 초반 복잡도 조절

**아쉬운 점:**
- 소셜/경쟁 요소 (리더보드, 친구 대전) 부재

---

## 8. 테스트 / 품질 보증 — 8 / 10

**강점:**
- 10개 테스트 파일, 100+ 테스트 케이스 (1,449 LOC)
- 데이터 정합성 검증 (유닛/적/유물/하이브리드 전수 검사)
- 시스템 로직 검증 (머지 대칭성, 유물 효과 스태킹, 시너지)
- 밸런스 상수 범위 검증

**아쉬운 점:**
- UI/위젯 테스트 부재
- 통합(integration) 테스트 미구현
- Flame 컴포넌트 행동 테스트 없음

---

## 9. 저장 / 데이터 관리 — 9 / 10

**강점:**
- 영구 저장 + 중간 저장 + 해금 상태 3중 구조
- 앱 백그라운드 전환 시 자동 저장 (`didChangeAppLifecycleState`)
- 런 종료 시 자동 삭제
- 이어하기 기능 완비

**아쉬운 점:**
- `shared_preferences` 기반이라 대용량 데이터 시 한계 가능

---

## 10. 수익화 설계 — 8 / 10

**강점:**
- 비침습적 광고 (보상형 ×2, 리롤, 부활)
- F2P 완전 플레이 가능
- 배틀패스/광고제거 IAP 구조 준비

**아쉬운 점:**
- 실제 광고 SDK 연동 미구현 (슬롯만 존재)
- 과금 포인트가 적어 ARPU 낮을 수 있음

## 총평

인디 모바일 게임으로서 설계 완성도와 콘텐츠 깊이가 매우 뛰어남.
코드 품질과 확장성도 상급. UI 정보량 최적화, 햅틱 피드백 추가,
UI 테스트 보강, 소셜 기능이 추가되면 상용 출시 수준에 충분히 도달 가능.

### 개선 우선순위

1. **높음**: 햅틱 피드백 추가, BGM/SFX 다양화
2. **중간**: UI 테스트 추가, 후반 밸런스 플레이테스트
3. **낮음**: 소셜 기능 (리더보드), 광고 SDK 연동
