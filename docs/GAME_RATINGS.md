## 3. 밸런스 설계 — 9.5 / 10

**레퍼런스 대비 강점:**
- `balance_config.dart` 단일 소스 (50+ 상수) — 산업 표준 데이터 드리븐 밸런싱
- 다축 스케일링 공식:
  ```
  적 HP = base × 1.08^wave × (1 + unitCount × 0.12)
  적 수 = (baseTier + wave×0.8) × (1 + unitCount × 0.04)
  적 속도 = base × (1 + unitCount×0.02) × (1 + max(0,wave-30)×0.005)
  ```
- 유물 트레이드오프 설계 (전쟁의 신: ATK 3배 / HP -50%, 미다스: ATK 0 / 골드 전환)
- 경제 이중 스케일링 (구매 횟수 1.15× + 보유 수 +3골드)
- 수학적으로 검증 가능한 밸런스 공식

**비교:** 뱀서는 단일 축 스케일링, 아쳐로는 레벨 기반 선형 스케일링 — Paw Defense의 3축 비선형 스케일링이 전략적 깊이에서 우위.

## 6. 게임 필(Game Feel) — 9.5 / 10

**레퍼런스 대비 강점:**
- **유닛 궤도 회전**: "All Aboard" 스타일 성벽 주위 공전, 웨이브/유닛수에 따라 가속 + 스프라이트 좌우반전
- **투사체 트레일 + 타입별 모양**: 8종 유닛별 고유 픽셀 모양(화살/검기/마법구/바위/수리검/깃털/힐볼트/아케인) + 8프레임 잔상
- **적 스웜 밀도**: 2배 적 수 × 0.55 HP → 화면 가득 우글거리는 느낌, ±15% 속도 편차
- **호밍 골드 파티클**: VS XP 보석 스타일 — 사망 시 비산 후 성벽으로 가속 수렴
- **충격파 링**: 보스 사망 시 24개 파티클 방사형 확산
- **반응형 배경**: 게임 강도에 따라 네이비→크림슨 색상 시프트 + 40개 별 파티클 + 방사형 펄스
- **스킬 풀스크린 오버레이**: 8종 스킬별 화면 가득 이펙트 (화살비/메테오/서리/전쟁함성/폭풍/마력폭발/암살표식/힐)
- **스크린 플래시**: 보스 처치(오렌지), 벽 위기(빨강), 진화(골드), 하이브리드(보라), 퍼펙트 웨이브(초록), 스킬 발동, 콤보 티어 — 7종
- **히트스탑 + 슬로모션 + 줌펀치**: 3중 주스 시스템
- **유닛 idle 보블링**: 타겟 없을 때 호흡 애니메이션
- **유닛 공격 squash & stretch**: 반동 + 찌그러짐 효과
- **진화 유닛 골드 글로우 오라**: 상시 발광 효과
- **하이브리드 유닛 보라 쉬머**: 차별화된 시각 정체성
- **파티클 16종+**: 골드/적 사망/보스 폭발/머지/벽 히트/웨이브/크리티컬/체인킬/하이브리드/콤보/투사체/스킬/충격파 링/골드비산/스케일드사망/스킬활성화
- **데미지 넘버 6종 타입**: 일반/크리티컬/힐/DoT/골드/방어 — 각각 다른 색상, 크기, 아웃라인, 포맷
- **햅틱 피드백 3단계**: Light(적중)/Medium(머지/스킬)/Heavy(보스/진화/게임오버)
- 배속(1x/2x) 토글

**비교:** 뱀서의 시각적 스노우볼링 + All Aboard의 궤도 시스템 참고. 킹덤러쉬보다 압도적으로 풍부한 파티클/트레일/배경 반응 피드백.

## 총평

레퍼런스 게임(뱀서, 킹덤러쉬, 아쳐로)과 직접 비교해도 대등하거나 우위에 있는 영역이 다수.
특히 3축 적 스케일링, 28종 하이브리드 시스템, 웨이브 변형은 경쟁작에 없는 고유 차별점.
플래시/햅틱/히트스탑/줌펀치에 더해 **시각적 스펙터클 6 Phase 대개편** 완료:
유닛 궤도 회전(All Aboard 스타일), 투사체 트레일+8종 모양, 적 스웜 밀도, 호밍 골드비산,
반응형 배경(강도 연동), 스킬 풀스크린 오버레이까지 구현하여
뱀파이어 서바이버즈 수준의 시각적 스노우볼링을 달성.
사업자 없이 개인으로 출시 가능한 상용 품질에 도달한 상태.

### 남은 개선 사항

1. **폴리싱**: 추가 BGM 트랙, 적응형 오디오 (위기/보스 BGM 전환)
2. **에셋 교체**: 코드 생성 픽셀아트 → 전문 스프라이트시트 (구조는 준비 완료)
