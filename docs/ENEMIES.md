## 특수 행동 (defense_enemy.dart)

| 타입 | 행동 |
|------|------|
| **shielded** | 전방에서 오는 공격 데미지 50% 감소 (dot product 판정) |
| **bomber** | 성벽 도달 시 2x 데미지 폭발 후 즉사. 일반 공격 안 함 |
| **healer** | 3초마다 주변 50px 아군 HP 10% 회복 |
| **boss** | 1.5x 크기, 빨간 글로우, 공속 0.5 고정, 유물 드랍 |
| **bat** | 사인파 이동. 대공(canHitAir) 유닛만 공격 가능 |

## 난이도 스케일링 (balance_config.dart)

```
HP = baseHp * 1.08^wave * (1 + units * 0.12)
Speed = baseSpeed * (1 + units * 0.02) * (1 + max(0, wave-30) * 0.005)
       * relicManager.enemySpeedMultiplier  // 시간의 모래: x0.7
Count = (baseTier + wave * 0.8) * (1 + units * 0.04)
```

## 원소 & DoT 시스템 (defense_enemy.dart + projectile.dart)

### 원소 폭풍 유물 (relic_elemental)
투사체 피격 시 랜덤 원소 중 하나 적용:

| 원소 | 효과 | 지속 시간 | 설명 |
|------|------|----------|------|
| 🔥 불 | DPS = ATK × 30% | 3초 | 지속 화상 데미지 |
| 🧊 얼음 | 속도 -40% | 2초 | 이동 둔화 (applySlow) |
| 🧪 독 | DPS = ATK × 15% | 5초 | 장시간 약한 독 데미지 |

- DoT 틱 간격: **0.5초** (`_dotTickInterval`)
- `applyDot(dps, duration, type)` 메서드로 처리
- 여러 원소 중첩 가능 (같은 타입은 갱신)

### 분열탄 유물 (relic_split_shot)
투사체가 적 피격 시 ±45° 방향으로 자식 투사체 2개 생성:
- 자식 데미지: 원본의 **50%**
- 자식은 재분열하지 않음 (`_isSplit` 플래그)
- 대량 적에 효과적 (후반 웨이브 30+ 시너지)

## 유물 관련 적 상호작용

| 유물 | 적에 대한 효과 |
|------|---------------|
| 시간의 모래 | 전체 적 속도 x0.7 |
| 가시 갑옷 | 성벽 피격 시 적에게 데미지 10 반사 |
| 연쇄 번개 | 적 처치 시 주변 적 1마리에 50% 데미지 |
| 빙결의 오라 | 성벽 근처 적 둔화 -20% |
| 광전사 | HP<30% 시 모든 유닛 ATK x2 → 적 빠르게 처리 |
| 원소 폭풍 | 피격 시 랜덤 불/얼음/독 적용 (위 표 참조) |
| 분열탄 | 피격 시 ±45° 자식 투사체 2개 (데미지 50%) |
| 적 전향 | 처치 시 5% 확률로 빈 슬롯에 무료 유닛 배치 |
