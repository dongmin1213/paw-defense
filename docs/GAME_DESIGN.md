# Game Design Document

## 게임 컨셉
횡스크롤 보스러시 액션. 스테이지 없이 바로 보스전. 총 8개 보스.

## 월드 설정
- 해상도: 800x600 (고정)
- 중력: 980
- 지면 Y: 500

## 플레이어 메카닉

### 기본 스탯
| 항목 | 값 |
|------|-----|
| 이동속도 | 200 |
| 점프력 | -450 |
| 대시속도 | 500 |
| 대시지속 | 0.2초 |
| 대시쿨타임 | 0.8초 |
| 최대HP | 3 (하트) |
| 무적시간 | 1.5초 |
| 크기 | 40x50 |

### 사격
| 항목 | 값 |
|------|-----|
| 탄속 | 400 |
| 데미지 | 1.0 |
| 연사속도 | 0.15초 |
| 방향 | 마지막 이동방향 (기본: 오른쪽) |

### 필살기 (Special Attack)
| 항목 | 값 |
|------|-----|
| 게이지 최대 | 100 |
| 적중당 충전 | 8 |
| 필살기 데미지 | 15.0 |
| 필살기 비주얼 | 큰 탄환 + 오렌지 글로우 |

### 조작 (터치 UI)
- **좌/우 방향키**: 이동 (누르고 있기)
- **SHOOT**: 사격 (누르고 있기 = 연사)
- **JUMP**: 점프
- **DASH**: 대시 (현재 이동방향으로)
- **SP**: 필살기 (게이지 100일 때만 활성)

## 보스 시스템

### 공통 구조
- 각 보스는 `BossBase` 상속
- N개 페이즈 (HP 균등 분배로 전환)
- 피격시 흰색 플래시
- 플레이어 접촉시 데미지

### Boss 1: Stone Guardian (구현 완료)
- **HP**: 80
- **페이즈**: 3단계
- **Phase 1** (HP 100%~66%)
  - 수평 탄환 1발, 1.5초 간격
  - 부드러운 상하 움직임
- **Phase 2** (HP 66%~33%)
  - 수평 탄환 2발, 1.2초 간격
  - 그라운드 슬램 (5초 간격) → 충격파 4발
  - 슬램: 상승(0.3초) → 낙하(0.2초) → 대기(0.7초) → 복귀(0.5초)
- **Phase 3** (HP 33%~0%)
  - 수평 3발 or 유도탄, 0.8초 간격 (랜덤)
  - 그라운드 슬램 3.5초 간격
  - 빠른 상하 움직임
- **비주얼**: 사각형 몸통 + 머리 + 눈(페이즈별 색 변화) + 주먹 + 균열

## 적 탄환 패턴
| 패턴 | 설명 |
|------|------|
| straight | 직선 이동 |
| sine | 사인파 궤적 |
| aimed | 플레이어 방향 유도 |
| falling | 낙하형 |

## UI 구성
- **HUD**: 좌상단 HP 하트, 게이지바 / 우상단 보스 이름+HP바
- **조작**: 좌하단 방향키, 우하단 액션버튼 4개
- **메인메뉴**: 8개 보스 카드 그리드 (잠금/해금 표시)
- **게임오버/승리**: 오버레이 화면 + 재시작/메뉴 버튼
