# The Bichon's Run — Game Design Document

## 게임 컨셉
Idle Slayer 스타일 반방치 오토러너. 비숑 프리제가 자동으로 달리며 적을 처치하고 코인을 모은다.
직접 플레이(탭 점프)하면 효율적이지만, 방치해도 코인이 모이는 구조.

## 조작
- **탭** = 점프 (공중 적 처치, 장애물 회피, 공중 코인 수집)
- **방치** = 자동 달리기 + 바닥 적 자동 처치 + 코인 자동 수집
- **오프라인** = CpS(초당코인) 기반 보상

## 모드
- **적극 플레이**: 탭 입력 감지 → 공중 적 + 장애물 생성 → 높은 보상
- **방치 모드**: 5초간 입력 없으면 전환 → 장애물 미생성 → 바닥 적만 자동 처치
- 적극 플레이 시 코인 x1.5 보너스

## 핵심 시스템

### 1. 몬스터
- **바닥 적**: 자동 처치 (달리면서 베기). HP 있음 — 공격력 < HP면 여러 번 때려야 함
- **공중 적**: 점프로 처치 (적극 플레이 = 3배 코인)
- 지역별 고유 몬스터, 상위 지역일수록 HP↑ 드랍↑

| 지역 | 바닥 적 | 공중 적 | 코인 배율 |
|------|--------|--------|----------|
| 초원 | 슬라임, 버섯 | 새, 나비 | x1 |
| 숲 | 고블린, 거미 | 박쥐, 요정 | x3 |
| 사막 | 전갈, 미라 | 독수리, 모래령 | x10 |
| 설산 | 눈골렘, 늑대 | 눈올빼미, 얼음정령 | x30 |
| 화산 | 화염임프, 용인 | 불박쥐, 피닉스 | x100 |

### 2. 콤보
- 적 처치 시 콤보 +1 (점프 처치 = +2)
- 배율: `1 + combo * 0.05` (20콤보 = x2.0)
- 3초간 미처치 시 콤보 리셋

### 3. 장비 (단계적 해금)
- **검** (기본): 바닥 적 자동 처치
- **활** (소울 해금): 점프 중 자동 화살 → 원거리 적 처치
- **장갑** (소울 해금): 처치 시 추가 코인 드랍
- **망토** (소울 해금): 2단 대시, 이동속도 보너스

### 4. 일반 업그레이드 (코인, 초월 시 리셋)

| 업그레이드 | 최대Lv | 기본비용 | 효과 |
|-----------|--------|---------|------|
| 이동속도 | 25 | 10 | +5% per lv |
| 코인 획득 | 25 | 15 | +8% per lv |
| 공격력 | 20 | 20 | +10% per lv |
| 점프력 | 15 | 25 | +5% per lv |
| 더블점프 | 1 | 500 | 공중 점프 1회 |
| 코인 자석 | 10 | 30 | 흡수 반경 +20px per lv |
| 콤보 유지 | 5 | 100 | 리셋 대신 감소 |
| 장비 Lv | 각 50 | 장비별 | 장비 성능 강화 |

비용 공식: `baseCost * 1.15^level`

### 5. 초월 (Ascension)
- **조건**: 누적 코인 ≥ `10000 * 3^ascensionCount`
- **리셋**: 일반 업글, 거리, 코인
- **보상**: 소울 = `max(1, floor(log10(totalCoins) - 3))`
- **유지**: 동료, 영구 업글, 소울 잔고

### 6. 영구 업그레이드 (소울, 리셋 안 됨)

| 업그레이드 | 최대Lv | 소울비용 | 효과 |
|-----------|--------|---------|------|
| 코인 배율 | ∞ | 1,2,4,8... | +25% 모든 코인 per lv |
| 시작 속도 | 10 | 2 each | 초월 후 +10% 시작 속도 |
| 오프라인 효율 | 10 | 3 each | 오프라인 수익 +15% |
| 지역 해금 | 4 | 5,15,50,150 | 숲/사막/설산/화산 해금 |
| 활 해금 | 1 | 10 | 활 장비 |
| 장갑 해금 | 1 | 30 | 장갑 장비 |
| 망토 해금 | 1 | 80 | 망토 장비 |
| 자동 공중적 처치 | 1 | 50 | 방치 중에도 공중 적 자동 처치 |
| 자동 업글 | 1 | 100 | 코인 차면 자동 구매 |
| 콤보 부스터 | 5 | 5 each | 콤보당 +0.02 추가 배율 |

### 7. 보스 (500m마다)
- 화면 오른쪽에 큰 적 등장
- 자동 공격 + 탭으로 추가 공격 (2배 DPS)
- HP 바 표시, 10초 제한, 처치 시 코인 폭발 + 소울

### 8. 미니이벤트
- **보물상자**: 터치하면 코인/소울/동료 중 하나
- **코인 러시**: 30초간 코인 대량 출현
- **황금 적**: 처치 시 x10 보상

## 동료 시스템
- 달리다 랜덤 등장 → 터치로 영입
- 패시브 버프, 동시 장착 슬롯 (1→4개)
- 초월해도 유지 — 장기 수집 동기

| 동료 | 희귀도 | 출현확률 | 기본효과 | Lv10 효과 |
|------|--------|---------|---------|----------|
| 고양이 | 일반 | 20% | 코인 +5% | 코인 +15% |
| 햄스터 | 일반 | 20% | 속도 +5% | 속도 +15% |
| 토끼 | 일반 | 20% | 점프력 +5% | 점프력 +15% |
| 부엉이 | 레어 | 10% | 소울 +10% | 소울 +25% |
| 여우 | 레어 | 10% | 콤보유지 +1초 | 콤보유지 +3초 |
| 펭귄 | 레어 | 8% | 장애물 무시 3% | 장애물 무시 10% |
| 늑대 | 에픽 | 5% | 공격력 +15% | 공격력 +35% |
| 유니콘 | 에픽 | 4% | 전체 스탯 +5% | 전체 스탯 +12% |
| 드래곤 | 전설 | 2% | 전체 스탯 +8% | 전체 스탯 +20% |
| 피닉스 | 전설 | 1% | 초월 소울 +20% | 초월 소울 +50% |

## 날씨/시간 시스템

### 시간대 (기기 시간)
| 시간 | 상태 | 효과 |
|------|------|------|
| 6:00~18:00 | 낮 | 기본 |
| 18:00~22:00 | 저녁 | 코인 +20%, 석양 배경 |
| 22:00~4:00 | 밤 | 소울 +50%, 희귀적↑ |
| 4:00~6:00 | 새벽 | 전설 동료 2배, 안개 |

### 날씨 (3~5분 주기)
| 날씨 | 확률 | 효과 |
|------|------|------|
| 맑음 | 50% | 기본 |
| 비 | 20% | 코인 +30% |
| 눈 | 15% | 희귀적 +50% |
| 폭풍 | 10% | 모든 드랍 x2, 장애물 x2 |
| 무지개 | 5% | 30초간 전부 2배 |

### 특수 이벤트 (평균 10분마다)
- **유성우**: 하늘에서 코인 쏟아짐 (30초)
- **골든 아워**: 모든 적 황금색, 코인 x5 (20초)
- **동료 집회**: 동료 출현율 5배 (1분)

## 광고 수익화

### 원칙
- 강제 광고 없음 — 게임 플레이 중 끊기는 광고 절대 없음
- 보상형 광고 중심 — 유저 선택, 확실한 보상
- 배너는 상점에서만 — 게임 화면에 배너 없음

### 보상형 광고
| 위치 | 보상 | 빈도 |
|------|------|------|
| 오프라인 복귀 | 오프라인 보상 x2 | 복귀당 1회 |
| 상점 | 5분간 코인 x2 | 30분당 1회 |
| 보스 처치 후 | 보스 보상 x2 | 보스당 1회 |
| 초월 화면 | 소울 +20% | 초월당 1회 |
| 동료 등장 시 | 등급 1단계 업 | 하루 5회 |

### 인터스티셜
- 초월 직후 로딩 화면
- 5번째 업그레이드 구매마다
- 하루 최대 10회

## 코인 경제 공식
```
바닥 적 코인 = baseValue * 지역배율 * 코인업글 * 소울배율 * 콤보배율
공중 적 코인 = 바닥 적 * 3
CpS = (평균 적 출현율 * 평균 코인) / 초
오프라인 보상 = CpS * 경과초 * 0.3 * 오프라인업글보너스
```

## 확장 로드맵
- 적 진화 (3단계, 처치 수 기반)
- 업글 티어 (만렙 → 다음 티어 해금)
- 울트라 초월 (초월 10회 → 소울까지 리셋 + 디바인 포인트)
- 퀘스트/업적 시스템
- 미니언 시스템 (자동 수입원)
- 크래프팅 (재료 드랍 → 아이템 제작)
- 추가 지역/차원 확장
- 캐릭터 스킨/코스튬
