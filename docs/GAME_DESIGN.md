# Game Design Document
# The Bichon's Odyssey

## 게임 컨셉
비숑 캐릭터들의 횡스크롤 액션 어드벤처. 컵헤드식 레트로 느낌 + 메이플 도트 감성.
스테이지 탐험 → 일반 적 처치 → 보스전 구조. 5개 직업 선택 가능.

## 영감
- **컵헤드**: 간단한 조작, 레트로 스타일, 모험 구조 (오버월드 → 스테이지)
- **메이플스토리**: 잘 짜여진 도트 그래픽, 직업 시스템, 횡스크롤 전투

## 월드 설정
- 해상도: 800x600 (고정)
- 중력: 980
- 지면 Y: 500

## 직업 시스템 (5직업)

### 1. Knight (기사)
- **무기**: 대검
- **공격방식**: 근거리 베기 (넓은 범위, 짧은 사거리)
- **특수능력**: 실드 블록 (피격 무효화)
- **필살기**: 지면 강타 (전방 충격파)
- **스탯**: HP 5, 이동속도 160, 공격력 3.0

### 2. Assassin (암살자)
- **무기**: 쌍단검
- **공격방식**: 빠른 근접 연타
- **특수능력**: 그림자 텔레포트 (적 뒤로 이동)
- **필살기**: 연속 난무 (다단히트)
- **스탯**: HP 3, 이동속도 250, 공격력 1.5

### 3. Archer (궁수)
- **무기**: 활
- **공격방식**: 원거리 화살 (차징 가능)
- **특수능력**: 백스텝 (후방 도약 + 화살 발사)
- **필살기**: 화살비 (하늘에서 화살 쏟아짐)
- **스탯**: HP 3, 이동속도 200, 공격력 2.0 (풀차지 5.0)

### 4. Mage (마법사)
- **무기**: 지팡이
- **공격방식**: 마법탄 발사 (관통)
- **특수능력**: 원소 전환 (불/얼음)
- **필살기**: 메테오 (화면 광역)
- **스탯**: HP 3, 이동속도 180, 공격력 2.5

### 5. Gunner (건너/해적)
- **무기**: 캐논
- **공격방식**: 폭발탄 (착탄시 범위 데미지)
- **특수능력**: 넉백 샷 (적 밀어내기)
- **필살기**: 포격 (전방 대형 폭발)
- **스탯**: HP 4, 이동속도 170, 공격력 4.0 (느린 연사)

## 게임 플로우
```
타이틀 → 직업 선택 → 오버월드 맵
  → 스테이지 선택 → 탐험 구간 (일반 적) → 보스전
  → 클리어 → 오버월드 복귀 (다음 스테이지 해금)
```

## 스테이지 구조

### 각 스테이지 = 탐험 + 보스
1. **탐험 구간**: 횡스크롤 진행, 플랫폼 점프, 일반 적 처치
2. **보스 게이트**: 탐험 구간 끝에 보스방 진입
3. **보스전**: 기존 보스러시 전투

### 스테이지 목록
| # | 스테이지명 | 테마 | 보스 |
|---|-----------|------|------|
| 1 | 돌의 성채 | 고대 유적 | Stone Guardian |
| 2 | 그림자 골목 | 어두운 도시 | Shadow Dasher |
| 3 | 마녀의 탑 | 마법의 탑 | Bullet Witch |
| 4 | 강철 요새 | 기계 공장 | Iron Colossus |
| 5 | 거울의 미궁 | 거울 궁전 | Mirror Trickster |
| 6 | 벌집 동굴 | 거대 벌집 | Hive Queen |
| 7 | 폭풍 봉우리 | 산 정상 | Storm Elemental |
| 8 | 암흑의 왕좌 | 최종 성 | The Overlord |

## 일반 적 (스테이지 탐험용)

### 공통 적
- **Slime**: 바닥 이동, 접촉 데미지
- **Bat**: 공중 사인파 이동
- **Skeleton**: 바닥 이동 + 뼈 투척

### 스테이지별 특수 적
| 스테이지 | 적 | 행동 |
|---------|-----|------|
| 돌의 성채 | GolemShard | 느린 이동, 높은 HP |
| 그림자 골목 | ShadowRat | 빠른 이동, 낮은 HP |
| 마녀의 탑 | SpellOrb | 공중 떠다니며 마법탄 |

## 플레이어 공통 메카닉

### 기본 조작
- **좌/우**: 이동
- **ATTACK**: 공격 (직업별 다름)
- **JUMP**: 점프
- **SKILL**: 특수능력 (직업별 다름)
- **SP**: 필살기 (게이지 100일 때)

### 공통 스탯
| 항목 | 설명 |
|------|------|
| 점프력 | -450 (전 직업 동일) |
| 대시속도 | 500 |
| 대시지속 | 0.2초 |
| 대시쿨타임 | 0.8초 |
| 무적시간 | 1.5초 |
| 크기 | 40x50 |

### 필살기 게이지
| 항목 | 값 |
|------|-----|
| 게이지 최대 | 100 |
| 적중당 충전 | 8 |

## 보스 상세

### Boss 1: Stone Guardian (구현 완료)
- **HP**: 80, **페이즈**: 3단계
- Phase 1: 수평 탄환 1발, 1.5초 간격
- Phase 2: 수평 2발 + 그라운드 슬램(5초)
- Phase 3: 수평 3발/유도탄 + 슬램(3.5초)

### Boss 2: Shadow Dasher
- **HP**: 60, **페이즈**: 3단계
- 빠른 대시 공격, 텔레포트, 분신 소환
- Phase 1: 좌우 대시 공격
- Phase 2: 텔레포트 + 칼날 투척
- Phase 3: 분신 2체 + 연속 대시

### Boss 3: Bullet Witch
- **HP**: 70, **페이즈**: 3단계
- 다양한 탄막 패턴, 공중 부유
- Phase 1: 원형 탄막
- Phase 2: 나선형 탄막 + 유도탄
- Phase 3: 레이저 빔 + 탄막 복합

### Boss 4: Iron Colossus
- **HP**: 150, **페이즈**: 3단계
- 거대 보스, 느리지만 강력한 공격
- Phase 1: 주먹 내려찍기
- Phase 2: 미사일 발사 + 돌진
- Phase 3: 레이저 + 파츠 파괴 가능

### Boss 5: Mirror Trickster
- **HP**: 65, **페이즈**: 3단계
- 분신으로 혼란, 진짜만 데미지 가능
- Phase 1: 분신 1체
- Phase 2: 분신 2체 + 위치 셔플
- Phase 3: 거울 반사 공격

### Boss 6: Hive Queen
- **HP**: 90, **페이즈**: 3단계
- 미니언 소환, 벌떼 관리
- Phase 1: 일벌 소환 (3마리)
- Phase 2: 병정벌 + 독침 패턴
- Phase 3: 벌떼 러시 + 여왕벌 직접 공격

### Boss 7: Storm Elemental
- **HP**: 80, **페이즈**: 3단계
- 번개/바람/비 환경 효과
- Phase 1: 번개 낙뢰
- Phase 2: 돌풍 (플레이어 밀기) + 번개
- Phase 3: 폭풍우 (시야 제한) + 낙뢰 연속

### Boss 8: The Overlord
- **HP**: 120, **페이즈**: 4단계
- 이전 보스들의 패턴 복합
- Phase 1: Guardian 패턴
- Phase 2: Dasher + Witch 패턴
- Phase 3: Colossus + Elemental 패턴
- Phase 4: 고유 최종 패턴

## 적 탄환 패턴
| 패턴 | 설명 |
|------|------|
| straight | 직선 이동 |
| sine | 사인파 궤적 |
| aimed | 플레이어 방향 유도 |
| falling | 낙하형 |
| circular | 원형 확산 |
| spiral | 나선형 |
| laser | 직선 레이저 (경고 후 발사) |

## UI 구성
- **HUD**: 좌상단 HP 하트 + 게이지바 / 우상단 보스HP (보스전시)
- **조작**: 좌하단 방향키, 우하단 액션버튼 (ATTACK, JUMP, SKILL, SP)
- **오버월드**: 스테이지 노드 맵 (해금/잠금 표시)
- **직업선택**: 5개 직업 카드 + 스탯 미리보기
- **게임오버/승리**: 오버레이 화면 + 재시작/메뉴 버튼
