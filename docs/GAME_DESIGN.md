# The Bichon's Run — Game Design Document

## 게임 컨셉

Idle Slayer 스타일 **반방치 오토러너**. 비숑 프리제(Bichon Frise)가 자동으로 달리며 적을 처치하고 코인을 모은다.

- **직접 플레이(탭 점프)** → 공중 적 처치 + 장애물 회피 + 동료 수집 = 고효율
- **방치** → 바닥 적 자동 처치 + 코인 자동 수집 = 저효율이지만 성장 유지
- **오프라인** → CpS(초당코인) 기반 보상 (30% 효율)

---

## 조작

| 입력 | 행동 |
|------|------|
| 탭 | 점프 (공중 적 처치, 장애물 회피, 공중 코인 수집) |
| 탭 (보스전) | 추가 공격 (2배 DPS) |
| 방치 (5초 무입력) | 방치 모드 전환 — 장애물/공중적 미생성 |

### 적극/방치 모드

| | 적극 플레이 | 방치 모드 |
|--|-----------|---------|
| 판정 | 5초 내 탭 입력 | 5초간 무입력 |
| 바닥 적 | 자동 처치 | 자동 처치 |
| 공중 적 | 생성됨 (점프 처치 = x3 코인) | 미생성 |
| 장애물 | 생성됨 (회피 = 콤보 유지) | 미생성 |
| 동료 | 필드 출현 | 미출현 |
| 코인 보너스 | x1.5 | x1.0 |

## 첫 5분 경험 (온보딩 목표)

```
0:00  타이틀 "The Bichon's Run" → 탭하여 시작
0:10  비숏이 달리기 시작
0:20  첫 바닥 적(슬라임) 자동 처치 → 코인 "+1" 팝업
0:30  공중 적(새) → 탭 점프로 처치 → "+3" (3배)
0:50  바위 장애물 → 안 피하면 속도 감소 체험
1:00  코인 카운터 차오름 → 상점 버튼
1:30  첫 업그레이드 "이동속도 Lv.2" 구매
2:30  동료(고양이) 필드 등장 → 터치 수집 → 코인+5% 버프
3:00  콤보 시스템 자연 체험 (연속 처치)
5:00  업그레이드 2~3개 구매 → 성장 실감
```

핵심: **처음 30초 안에 "자동 처치 + 점프 보너스 + 코인"을 체험**시킴.

## 핵심 시스템

### 1. 몬스터

#### 지역별 몬스터 (총 20종, 5지역 × 4종)

| 지역 | 바닥 적 | 공중 적 | 코인 배율 | 해금 |
|------|--------|--------|----------|------|
| 초원 (meadow) | 슬라임, 버섯 | 새, 나비 | x1 | 기본 |
| 숲 (forest) | 고블린, 거미 | 박쥐, 요정 | x3 | 소울 5 |
| 사막 (desert) | 전갈, 미라 | 독수리, 모래령 | x10 | 소울 15 |
| 설산 (snowfield) | 눈골렘, 늑대 | 눈올빼미, 얼음정령 | x30 | 소울 50 |
| 화산 (volcano) | 화염임프, 용인 | 불박쥐, 피닉스 | x100 | 소울 150 |

- **바닥 적**: 자동 처치. HP가 있어서 공격력 < HP면 여러 번 때려야 함
- **공중 적**: 점프로만 처치. 코인 x3. 적극 플레이 보상
- **황금 적**: 2% 확률 (골든아워 시 100%), 코인 x10

#### 적 데이터 구조 (enemy_data.dart)
```dart
EnemyData(
  id: 'slime', name: '슬라임', type: EnemyType.ground,
  hp: 1, coinDrop: 1, width: 24, height: 24,
  color: Color(0xFF4CAF50), accentColor: Color(0xFF388E3C),
  spawnWeight: 10,  // 출현 가중치
)
```

### 2. 콤보

- 적 처치 시 콤보 +1 (점프 처치 = +2)
- 배율: `1 + combo × 0.05` (20콤보 = x2.0)
- **3초** 미처치 시 콤보 리셋 (콤보유지 업글 시 비율 감소)
- 콤보 마일스톤 (10, 25, 50, 100) 시 파티클 이펙트

### 3. 장비 (단계적 해금)

> **현재 상태**: 소울 해금 구조만 구현, 실제 효과 미구현

| 장비 | 해금 | 효과 (계획) |
|------|------|-----------|
| 검 | 기본 | 바닥 적 자동 처치 |
| 활 | 소울 10 | 점프 중 자동 화살 → 원거리 적 처치 + 소울 보너스 |
| 장갑 | 소울 30 | 처치 시 추가 코인 드랍 (CpS 대폭 증가) |
| 망토 | 소울 80 | 2단 대시, 이동속도 보너스, 대시 중 무적 |

### 4. 일반 업그레이드 (코인 소모, 초월 시 리셋)

| 업그레이드 | 최대Lv | 기본비용 | 효과 |
|-----------|--------|---------|------|
| 이동속도 | 25 | 10 | +5% per lv |
| 코인 획득 | 25 | 15 | +8% per lv |
| 공격력 | 20 | 20 | +10% per lv |
| 점프력 | 15 | 25 | +5% per lv |
| 더블점프 | 1 | 500 | 공중 점프 1회 추가 |
| 코인 자석 | 10 | 30 | 흡수 반경 +20px per lv |
| 콤보 유지 | 5 | 100 | 리셋 대신 50/40/30/20/10% 감소 |

**비용 공식**: `baseCost × 1.15^level`

---

### 5. 초월 (Ascension)

코인 → 업그레이드 성장이 한계에 도달하면 초월하여 소울을 획득.

| 항목 | 내용 |
|------|------|
| 조건 | 누적 코인 ≥ `10000 × 3^ascensionCount` |
| 리셋 | 일반 업글 레벨, 거리, 코인 |
| 보상 | 소울 = `max(1, floor(log₁₀(totalCoins) - 3))` |
| 유지 | 동료, 영구 업글, 소울 잔고 |
| 연출 | 화이트아웃 애니메이션 → "초월 N회차" → 소울 보상 표시 |

첫 초월까지 약 30분~1시간 (적극 플레이 기준).

## 동료 시스템

### 개요
- 달리다 랜덤 등장 → **터치로 영입** (적극 플레이 시에만)
- 패시브 버프 제공, 동시 장착 슬롯 (1개 → 소울로 최대 4개)
- 코인 투자로 레벨업 (버프 강화)
- **초월해도 유지** — 장기 수집 동기

### 동료 목록 (10종)

| 동료 | 희귀도 | 출현확률 | 기본효과 | Lv10 효과 |
|------|--------|---------|---------|----------|
| 고양이 | 일반 | 20% | 코인 +5% | 코인 +15% |
| 햄스터 | 일반 | 20% | 속도 +5% | 속도 +15% |
| 토끼 | 일반 | 20% | 점프력 +5% | 점프력 +15% |
| 부엉이 | 레어 | 10% | 소울 +10% | 소울 +25% |
| 여우 | 레어 | 10% | 콤보유지 +1초 | 콤보유지 +3초 |
| 펭귄 | 레어 | 8% | 장애물 무시 3% | 장애물 무시 10% |
| 늑대 | 에픽 | 5% | 공격력 +15% | 공격력 +35% |
| 유니콘 | 에픽 | 4% | 전체 스탯 +5% | 전체 스탯 +12% |
| 드래곤 | 전설 | 2% | 전체 스탯 +8% | 전체 스탯 +20% |
| 피닉스 | 전설 | 1% | 초월 소울 +20% | 초월 소울 +50% |

### 동료 메카닉
- 출현: 평균 2분마다 1회 (적극 플레이 시만, 동료 집회 이벤트 시 5x)
- 레벨업 비용: `100 × rarityMultiplier × 1.3^level`
- 중복 영입 시 자동 레벨업 재료로 전환
- 장착 슬롯: 기본 1개 → 소울 영구 업글로 최대 4개
- 도감 완성 보너스 (전체 수집 시 특별 버프) — 계획 중

## 코인 경제

### 코인 획득 배율 스택

코인 획득 시 아래 배율이 모두 곱연산으로 적용됨:

```
최종코인 = 기본코인
  × 콤보배율          (1 + combo × 0.05)
  × 지역배율          (x1 ~ x100)
  × 적극모드배율      (적극 x1.5 / 방치 x1.0)
  × 코인업글배율      (lv25 = x3.0)
  × 소울코인배율      (영구 +25%/lv)
  × 동료코인배율      (장착 동료 버프)
  × 날씨배율          (비+30%, 폭풍x2, 무지개x2)
  × 시간대배율        (저녁+20%)
  × 골든아워배율      (이벤트 x5)
  × 무지개배율        (날씨 x2)
```

### 오프라인 보상

```
CpS = 적출현율(2/s) × 코인(1) × 지역배율 × 코인업글 × 소울배율 × 동료배율
    × 오프라인효율(0.3) × (1 + 오프라인업글보너스)

총보상 = CpS × clamp(경과초, 0, 86400)
```

- 최소 60초 경과해야 보상 팝업 표시
- 최대 24시간(86400초) 캡
- 광고 시청 시 x2

### 주요 밸런스 수치

| 수치 | 값 | 위치 |
|------|-----|------|
| 업글 비용 곱수 | 1.15^lv | balance_config.dart |
| 공중 적 코인 | x3 | balance_config.dart |
| 콤보 스택당 | +0.05 | balance_config.dart |
| 콤보 리셋 | 3초 | balance_config.dart |

| 황금 적 | x10 | enemy.dart |
| 오프라인 효율 | 30% | balance_config.dart |
| 초월 임계값 | 10000 × 3^n | balance_config.dart |
| 소울 공식 | max(1, log₁₀-3) | ascension_manager.dart |

## 광고 수익화

### 원칙
- **강제 광고 없음** — 게임 플레이 중 끊기는 광고 절대 없음
- **보상형 광고 중심** — 유저 선택, 확실한 보상
- **배너는 상점에서만** — 게임 화면에 배너 없음

### 현재 상태: 스텁 구현 (SDK 미연동)
`AdManager`는 API만 정의하고, 실제 광고 없이 즉시 보상 콜백 호출.
`google_mobile_ads` SDK 연동 시 `AdManager` 내부만 수정하면 됨.

### 보상형 광고 (Rewarded Video)

| 위치 | 보상 | 빈도 제한 |
|------|------|----------|
| 오프라인 복귀 팝업 | 오프라인 보상 x2 | 복귀당 1회 |
| 상점 내 버튼 | 5분간 코인 x2 부스트 | 30분당 1회 |
| 보스 처치 후 | 보스 보상 x2 | 보스당 1회 |
| 초월 화면 | 소울 +20% | 초월당 1회 |
| 동료 등장 시 | 등급 1단계 업 (레어→에픽) | 하루 5회 |

### 인터스티셜 (전면 광고)
- 초월 직후 로딩 화면에서
- 5번째 업그레이드 구매마다
- 하루 최대 10회 제한

## 확장 로드맵 (미래 계획)

### 근시일 내 구현 예정
1. 장비 효과 (활/장갑/망토 실제 로직)
2. 사운드 효과 (flame_audio)
3. 실제 광고 SDK 연동
4. 온보딩 튜토리얼

### 중기 확장
- 업적/퀘스트 시스템 (50+개, 방향성 제시)
- 보물상자/코인 러시 미니이벤트
- 적 진화 (3단계, 처치 수 기반)
- 업글 티어 (만렙 → 다음 티어 해금, 사실상 무한)

### 장기 확장
- 울트라 초월 (초월 10회 → 소울까지 리셋 + 디바인 포인트)
- 미니언 시스템 (자동 수입원)
- 크래프팅 (재료 드랍 → 아이템 제작)
- 추가 지역/차원 확장
- 캐릭터 스킨/코스튬
- PvP/소셜 요소
