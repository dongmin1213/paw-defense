# 🏰 동물 성벽 지키기 (가제) — Game Design Document

## 한 줄 요약
귀여운 동물 유닛을 배치·머지하여 성벽을 지키는 **방치형 로그라이트 타워디펜스**. 뱀서류의 자동전투 쾌감 + 기차방어의 머지 전략 + 방치형 성장을 결합.

---

## 1. 컨셉 & 차별점

### 레퍼런스 → 우리 게임

| 레퍼런스 | 가져온 것 | 우리만의 변형 |
|---------|----------|-------------|
| Vampire Survivors | 자동 공격, 파워 스파이럴, 로그라이트 런 | 이동 조작 대신 **유닛 배치** 조작 |
| 기차 방어 특급 | 머지 시스템, 유닛 추가=적 강화 딜레마 | **성벽** 중심 360° 방어 (기차의 양방향 → 사방) |
| 버섯커 키우기 | 다중 성장축, 귀여운 캐릭터, 방치 수익 | 가챠 대신 **머지 기반 성장** (조작감 있는 성장) |
| 스페이스 XYZ | 듀얼 이코노미, 웨이브 프레스티지 | 프레스티지 타이밍을 **플레이어 선택**으로 |

### 핵심 차별점
1. **머지 + 뱀서 하이브리드**: 유닛을 머지해서 강화하면서 사방에서 몰려오는 적을 막는 구조. 기존에 없는 조합.
2. **유닛 추가 딜레마**: 유닛을 많이 놓으면 적도 강해짐 (기차방어에서 검증된 메카닉). 양보다 질의 전략.
3. **방치 가능 + 적극 플레이 보상**: 자동 전투로 방치 가능하지만, 직접 머지/배치하면 2~3배 효율.
4. **귀여운 동물 유닛**: 코어 유저 + 캐주얼 유저 모두 흡입.

## 2. 게임 흐름

### 2.1 단판(런) 흐름 (20~30분)

```
런 시작 (성벽 HP 풀, 기본 유닛 1~2개)
    │
    ▼
웨이브 1~5: 약한 적 소수. 골드 수집 → 유닛 구매/배치 학습
    │
    ▼
웨이브 6~15: 적 수/종류 증가. 머지로 유닛 강화 필요
    │            중간 보상 선택 (뱀서식 3택 1)
    ▼
웨이브 16~25: 다방향 러시. 유닛 재배치/머지 전략 중요
    │            미니보스 등장 (10웨이브마다)
    ▼
웨이브 26~35: 특수 적 등장 (비행, 방패, 속도). 빌드 전환 요구
    │
    ▼
웨이브 36+: 무한 스케일링. 언제까지 버틸 수 있나
    │
    ▼
성벽 파괴 = 런 종료
    │
    ▼
보상 정산: 별(메타화폐) + 도감 진행 + 업적
    │
    ▼
영구 강화 → 다음 런 시작 (더 강해진 상태)
```

### 2.2 메타 루프 (런 간 진행)

```
런 반복 → 별 축적 → 영구 업그레이드 구매 → 더 높은 웨이브 도달
    │
    ▼ (마일스톤 달성)
새 유닛 종류 해금
새 지역/테마 해금 (초원 → 숲 → 사막 → 설산 → 화산)
새 난이도 해금 (노말 → 하드 → 나이트메어)
    │
    ▼ (장기 진행)
초월(Ascension) → 소울 획득 → 초월 스킬트리 → 재성장
```

## 3. 핵심 시스템

### 3.1 성벽 시스템

- **성벽**: 화면 중앙에 고정된 방어 거점. HP를 가짐.
- **성벽 HP**: 런 시작 시 풀. 적이 성벽에 도달하면 HP 감소. 0이 되면 런 종료.
- **성벽 레벨**: 메타 진행으로 영구 강화 (HP 증가, 자동 회복, 방어력).
- **성벽 배치 슬롯**: 성벽 주변 8~12개 슬롯에 유닛 배치.

```
         [슬롯]  [슬롯]  [슬롯]
    [슬롯]                    [슬롯]
    [슬롯]    [ 성  벽 ]     [슬롯]
    [슬롯]                    [슬롯]
         [슬롯]  [슬롯]  [슬롯]

    ← 적    ↑ 적    → 적    ↓ 적
        (사방에서 웨이브)
```

### 3.2 유닛 시스템

#### 유닛 배치
- **구매**: 골드로 랜덤 유닛 뽑기 (상점에서 3택 1 or 랜덤 배치)
- **배치**: 빈 슬롯에 드래그 & 드롭
- **방향**: 각 슬롯은 자동으로 가장 가까운 적 공격 (사거리 내)

#### 머지 시스템
- **같은 유닛 2개 → 합치면 1레벨 업** (기차방어의 3개 대신 2개로 — 모바일 편의성)
- 최대 레벨: 7 (Lv1~Lv7, 각 레벨마다 외형 변화)
- 머지 시 유닛 수 감소 → 적 스케일링 완화 (핵심 전략)

#### 유닛 종류 (초기 6종, 추후 확장)

| 유닛 | 타입 | 공격 | 특성 |
|------|------|------|------|
| 🐱 고양이 궁수 | 원거리 | 단일 타겟 | 기본 유닛. 빠른 공속 |
| 🐶 강아지 전사 | 근접 | 범위 | 성벽 앞에서 적 저지. 높은 체력 |
| 🐰 토끼 마법사 | 원거리 | 범위(스플래시) | 느리지만 광역. 밀집 적에 강함 |
| 🐻 곰 탱커 | 근접 | 단일 | 적 이동속도 감소. 높은 방어 |
| 🦊 여우 암살자 | 원거리 | 단일 | 높은 크리티컬. 보스에 강함 |
| 🐦 새 정찰병 | 원거리 | 관통 | 비행 적 공격 가능. 관통 화살 |

#### 유닛 진화 (머지 Lv7 도달 시)
- Lv7 유닛 + 특정 렐릭 보유 = **진화 유닛** (뱀서 무기 진화에서 착안)
- 예: 고양이 궁수 Lv7 + "화살비 렐릭" = **폭풍 궁수** (전체 화면 화살비)

### 3.3 적 시스템

#### 적 스폰
- **4방향**에서 동시 스폰 (상하좌우)
- 웨이브마다 방향별 적 구성이 다름 → 유닛 재배치 유도
- 웨이브 번호에 비례해 수/HP/속도 스케일링

#### 적 종류

| 적 | 특성 | 대응 |
|----|------|------|
| 슬라임 | 기본. 느리고 약함 | 아무 유닛 |
| 고블린 | 빠름. 낮은 HP | 빠른 공속 유닛 |
| 오크 | 느림. 높은 HP | 고DPS 유닛 |
| 박쥐 (비행) | 지상 유닛 무시. 성벽 직행 | 새 정찰병 필수 |
| 방패병 | 전방 방어. 관통/범위만 유효 | 마법사/관통 유닛 |
| 폭탄 고블린 | 성벽 도달 시 대폭발 (고피해) | 우선 처치 필요 |
| 힐러 | 주변 적 치유 | 먼저 처치 |
| 보스 | 10웨이브마다. 높은 HP, 특수 패턴 | 전체 화력 집중 |

#### 적 스케일링 (핵심 밸런스)
```
적 HP = baseHP * (1.08 ^ wave) * (1 + unitCount * 0.05)
적 수  = baseCount + floor(wave * 0.8)
```
- `unitCount * 0.05`: 유닛 수가 많을수록 적이 강해지는 딜레마
- 머지로 유닛 수를 줄이면 이 페널티 감소 → **머지의 전략적 가치**

### 3.4 인런 경제

#### 골드 (인런 화폐, 매 런 리셋)
| 획득처 | 양 |
|--------|-----|
| 일반 적 처치 | 1~3 |
| 엘리트 적 | 5~10 |
| 보스 처치 | 30~50 |
| 웨이브 클리어 보너스 | wave * 2 |

| 사용처 | 비용 |
|--------|------|
| 유닛 뽑기 (랜덤 1종) | 10 + (보유유닛 수 * 3) |
| 유닛 재배치 | 무료 |
| 성벽 수리 (HP 20% 회복) | 50 * 사용횟수 |
| 상점 리롤 | 5 |

> **유닛 구매 비용 공식**: `10 + (currentUnitCount * 3)`
> 유닛이 많을수록 추가 구매 비용 증가 → 양보다 질 유도

#### 인런 보상 선택 (뱀서식)
- **5웨이브마다** 3택 1 보상 제시:
  - 유닛 강화: "모든 궁수 공격력 +20%"
  - 성벽 강화: "성벽 HP 15% 회복"
  - 특수 효과: "10초간 전체 슬로우"
  - 렐릭 획득: "화살비 렐릭" (진화 재료)
- 보상 풀은 현재 보유 유닛/렐릭에 따라 가중치 조절

### 3.5 메타 진행 (런 간 영구 성장)

#### 별 (메타 화폐)
```
획득량 = floor(maxWave * 1.5) + bossKills * 10 + bonusMultiplier
```
- 높은 웨이브 = 더 많은 별
- 보스 처치 보너스
- 보상형 광고로 x2 가능

#### 영구 업그레이드 (별로 구매)

| 카테고리 | 업그레이드 | 최대Lv | 효과 |
|---------|----------|--------|------|
| **성벽** | 성벽 체력 | 50 | +5% HP/Lv |
| | 자동 회복 | 30 | +0.5 HP/초/Lv |
| | 방어력 | 30 | -2% 피해/Lv |
| **유닛** | 기본 공격력 | 50 | +3% ATK/Lv |
| | 공격 속도 | 30 | +2% ASPD/Lv |
| | 시작 유닛 | 5 | 런 시작 시 무료 유닛 +1/Lv |
| **경제** | 골드 획득량 | 30 | +5% 골드/Lv |
| | 유닛 할인 | 20 | -2% 유닛 비용/Lv |
| | 별 보너스 | 20 | +5% 별 획득/Lv |
| **특수** | 슬롯 확장 | 4 | 배치 슬롯 +1/Lv (8→12) |
| | 렐릭 확률 | 10 | +5% 렐릭 등장률/Lv |
| | 유닛 해금 | 6 | 새 유닛 종류 해금 |

#### 비용 공식
```
upgradeCost(lv) = baseCost * (1.12 ^ lv)
```
- 레벨당 12% 증가 (기존 프로젝트의 15%보다 완만 → 꾸준한 성장감)

### 3.6 초월 시스템 (장기 진행)

- **조건**: 누적 별 N개 이상 도달
- **효과**: 모든 영구 업그레이드 리셋 → **소울** 획득
- **소울 업그레이드**: 초월 전용 스킬트리
  - 시작 골드 보너스
  - 유닛 머지 시 추가 보너스
  - 새 유닛 타입 해금
  - 난이도 해금 (하드, 나이트메어)
  - 자동 머지 (방치 편의)
  - 자동 배치 (방치 편의)

```
초월 임계값 = 5000 * (3 ^ ascensionCount)
소울 획득량 = floor(sqrt(totalStars / 100))
```

### 3.7 렐릭 시스템

- **획득**: 보스 처치 시 드랍 (런 내 한정)
- **효과**: 인런 패시브 버프
- **진화 재료**: 특정 렐릭 + Lv7 유닛 = 진화

| 렐릭 | 효과 | 진화 조합 |
|------|------|----------|
| 화살비 | 궁수 공속 +30% | + 고양이 궁수 → 폭풍 궁수 |
| 불꽃 갑옷 | 적 접촉 시 화상 | + 강아지 전사 → 화염 기사 |
| 마나 수정 | 마법사 범위 +50% | + 토끼 마법사 → 대마법사 |
| 강철 방패 | 탱커 방어 +50% | + 곰 탱커 → 철벽 수호자 |
| 독 단검 | 암살자 치명타 +25% | + 여우 암살자 → 독안개 |
| 바람 깃털 | 정찰병 관통 +1 | + 새 정찰병 → 폭풍 매 |

### 3.8 웨이브 보상 선택 시스템 (뱀서식 레벨업)

5웨이브마다 **3택 1** 보상 카드:

**카드 등급**:
| 등급 | 확률 | 예시 |
|------|------|------|
| 일반 (회색) | 60% | 공격력 +10%, HP 회복 5% |
| 레어 (파랑) | 25% | 특정 유닛 공속 +30%, 골드 +50% |
| 에픽 (보라) | 12% | 렐릭 획득, 전체 유닛 레벨 +1 |
| 전설 (금) | 3% | 즉시 유닛 진화, 성벽 무적 10초 |

### 3.9 방치(Idle) 시스템

| 상태 | 판정 | 효과 |
|------|------|------|
| 적극 플레이 | 5초 내 터치 | 정상 플레이 |
| 방치 모드 | 5초 이상 무입력 | 자동 유닛 배치 (해금 시), 효율 70% |
| 오프라인 | 앱 종료 | CpS 기반 오프라인 별 축적 (최대 12시간) |

- **자동 머지**: 초월 해금 후, 방치 모드에서 3초마다 머지 가능한 유닛 자동 머지
- **자동 배치**: 초월 해금 후, 방치 모드에서 골드 충분 시 자동 유닛 구매+배치

## 4. 밸런스 설계

### 4.1 웨이브 스케일링

```dart
// 적 HP 스케일링
enemyHP(wave) = baseHP * pow(1.08, wave) * (1 + unitCount * 0.05)

// 적 수 스케일링
enemyCount(wave) = baseCount + (wave * 0.8).floor()

// 적 속도 (웨이브 30 이후 소폭 증가)
enemySpeed(wave) = baseSpeed * (1 + max(0, wave - 30) * 0.005)

// 보스 HP (10웨이브마다)
bossHP(wave) = 100 * pow(1.15, wave)
```

### 4.2 유닛 DPS 공식

```dart
unitDPS(level) = baseATK * pow(1.5, level - 1) * upgradeMultiplier
```
- 머지 1회 = DPS 1.5배 (2유닛 → 1유닛이지만 총 DPS는 0.75배)
- **3유닛 → 머지2회 → Lv3 1개**: DPS = base * 2.25 (3유닛 DPS base*3 대비 75%)
- **핵심**: 순수 DPS만 보면 머지가 손해. 하지만 **적 스케일링 감소** 때문에 머지가 유리

### 4.3 경제 밸런스

```
웨이브당 평균 골드 수입 = (적수 * 평균드랍) + 웨이브보너스
유닛 구매 간격 목표: 2~3 웨이브마다 1회
머지 가능 시점: 4~6 웨이브 (같은 유닛 2개 모을 때까지)
```

| 웨이브 | 예상 유닛 수 | 예상 머지 레벨 | 상태 |
|--------|------------|-------------|------|
| 1~5 | 2~3 | Lv1 | 생존 학습 |
| 6~10 | 3~5 | Lv1~2 | 첫 머지 경험 |
| 11~20 | 4~6 | Lv2~3 | 빌드 구축 |
| 21~30 | 5~8 | Lv3~5 | 파워 스파이럴 |
| 31~40 | 6~8 | Lv4~6 | 최적화 |
| 41+ | 6~8 | Lv5~7 | 진화 유닛 등장 |

### 4.4 파워 스파이럴 (뱀서에서 가져온 핵심)

```
웨이브 1~10:  긴장. 적 하나하나가 위협. 생존에 집중
웨이브 11~20: 성장. 머지로 강해지는 쾌감. "강해지고 있다"
웨이브 21~30: 파워 판타지. 적이 녹음. 화면 가득 이펙트
웨이브 31+:   재긴장. 스케일링이 따라옴. 전략 최적화 필요
웨이브 40+:   한계 도전. 어디까지 갈 수 있나
```

## 5. 게임필 (Game Feel)

### 5.1 이펙트 시스템 (기존 프로젝트 재활용)

| 이벤트 | 효과 |
|--------|------|
| 유닛 머지 | 파티클 폭발 + 줌펀치 + 스크린쉐이크(약) |
| 적 처치 | 처치 파티클 + 골드 팝업 |
| 보스 등장 | 경고 배너 + 스크린쉐이크(중) |
| 보스 처치 | 슬로모션 + 대폭발 + 줌펀치 + 렐릭 드랍 연출 |
| 성벽 피격 | 스크린쉐이크(강) + 붉은 화면 플래시 |
| 유닛 진화 | 히트스탑 + 줌인 + 진화 연출 + 슬로모션 복귀 |
| 웨이브 클리어 | 보상 카드 등장 연출 |

### 5.2 콤보 시스템
- 연속 처치 시 콤보 카운터 증가
- 콤보 등급: NICE(5) → GREAT(10) → EPIC(20) → INSANE(50)
- 등급 달성 시 골드 보너스 + 화면 이펙트

## 6. UI 구조

### 6.1 오버레이 구성

```
[게임 화면]
├── HUD (상단)

│   ├── 골드 표시 (롤링 애니메이션)

├── 유닛 상점 (하단)

│   └── 리롤 버튼
├── 일시정지 메뉴
│   ├── 계속하기
│   ├── 설정
│   └── 포기 (별 수령)

├── 시작 (런 시작)
├── 영구 업그레이드 상점 (별)
```

### 6.2 디자인 시스템

- 동물 유닛 → 픽셀아트 (기존 `PixelArt` 유틸 재활용)
- 모든 UI → `GameTheme` 정적 멤버 패턴 유지

## 7. 수익화 설계

### F2P + 보상형 광고 (비침습적)

| 광고 지점 | 보상 | 빈도 |
|----------|------|------|
| 런 종료 후 | 별 x2 | 매 런 1회 |
| 오프라인 복귀 | 오프라인 보상 x2 | 1일 3회 |
| 무료 유닛 뽑기 | 무료 유닛 1회 | 런당 2회 |
| 부활 | 성벽 HP 30% 회복 + 런 계속 | 런당 1회 |
| 일일 보너스 추가 | 보너스 별 지급 | 1일 1회 |

### 원칙
- **강제 광고 없음** (스페이스XYZ의 실패 교훈)
- **과금 벽 없음** (버섯커의 Lv100 벽 교훈)
- 광고 시청 = 편의/가속. 안 봐도 모든 콘텐츠 도달 가능
- 향후 확장: 광고 제거 패키지 ($3~5), 배틀패스 (월정액)

## 8. 저장 시스템

### 저장 데이터

```dart
// 메타 (영구)
- stars: int              // 별 (메타 화폐)
- souls: int              // 소울 (초월 화폐)
- upgrades: Map<String, int>  // 영구 업그레이드 레벨
- soulUpgrades: Map<String, int>  // 소울 업그레이드 레벨
- unlockedUnits: List<String>     // 해금된 유닛 종류
- achievements: Map<String, bool> // 업적 달성 여부
- dailyBonus: {...}        // 일일 보너스 상태
- stats: {...}             // 누적 통계 (총 처치수, 최고 웨이브 등)

// 인런 (중간 저장)
- currentWave: int
- wallHP: double
- gold: int
- units: List<UnitSaveData>   // 배치된 유닛 (종류, 레벨, 슬롯)
- relics: List<String>        // 보유 렐릭
- waveRewards: List<String>   // 선택한 웨이브 보상
```

### 저장 방식
- `SharedPreferences` (기존 시스템 재활용)
- 인런 저장: 웨이브 클리어마다 자동 저장 (기차방어의 저장 없음 문제 해결)
- 메타 저장: 런 종료/업그레이드 구매 시 저장

## 9. 콘텐츠 확장 계획

### Phase 1: 코어 (MVP)
- 성벽 + 6종 유닛 + 머지 + 기본 적 5종 + 보스 1종
- 인런 골드 경제 + 웨이브 보상 카드
- 메타 별 + 영구 업그레이드 10종
- 기본 UI (HUD, 상점, 메뉴)

### Phase 2: 깊이
- 렐릭 시스템 + 유닛 진화 6종
- 특수 적 3종 (비행, 방패, 폭탄)
- 초월 시스템 + 소울 스킬트리
- 업적 + 일일 보너스

### Phase 3: 확장
- 지역 테마 5종 (배경/적 비주얼 변화)
- 유닛 추가 6종 (총 12종)
- 난이도 모드 (하드, 나이트메어)
- 보상형 광고 연동

### Phase 4: 라이브
- 이벤트 웨이브 (한정 보상)
- 배틀패스
- 신규 유닛/렐릭 주기적 추가
- 커뮤니티 피드백 반영

## 11. 화면 방향

**결정 필요**: Portrait vs Landscape

| | Portrait (세로) | Landscape (가로) |
|---|---|---|
| 장점 | 한 손 조작, 모바일 자연스러움 | 넓은 전장, 기존 코드 호환 |
| 단점 | 전장이 좁음 | 양손 필요 |
| 추천 | 성벽 중심 + 유닛 배치에 적합 | — |

> **제안**: Portrait. 성벽이 중앙, 하단에 유닛 상점, 상단에 HUD. 한 손으로 유닛 드래그 가능.
