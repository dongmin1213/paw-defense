# 🏰 동물 성벽 지키기 (가제) — Game Design Document

## 한 줄 요약
귀여운 동물 유닛을 배치·머지하여 성벽을 지키는 **반방치 로그라이트 타워디펜스**. 뱀서류의 자동전투 쾌감 + 기차방어의 머지 전략 + 반방치 성장을 결합.

---

## 1. 컨셉 & 차별점

### 레퍼런스 → 우리 게임

| 레퍼런스 | 가져온 것 | 우리만의 변형 |
|---------|----------|-------------|
| Vampire Survivors | 자동 공격, 파워 스파이럴, 로그라이트 런 | 이동 조작 대신 **유닛 배치** 조작 |
| 기차 방어 특급 | 머지 시스템, 유닛 추가=적 강화 딜레마 | **성벽** 중심 360° 방어 (기차의 양방향 → 사방) |
| 버섯커 키우기 | 다중 성장축, 귀여운 캐릭터, 방치 수익 | 가챠 대신 **머지 기반 성장** (조작감 있는 성장) |
| 스페이스 XYZ | 듀얼 이코노미, 웨이브 프레스티지 | 프레스티지 타이밍을 **플레이어 선택**으로 |

### 핵심 차별점
1. **머지 + 뱀서 하이브리드**: 유닛을 머지해서 강화하면서 사방에서 몰려오는 적을 막는 구조. 기존에 없는 조합.
2. **유닛 추가 딜레마**: 유닛을 많이 놓으면 적도 강해짐 (기차방어에서 검증된 메카닉). 양보다 질의 전략.
3. **반방치 + 적극 플레이 보상**: 잠시 손 놓아도 바로 죽지 않지만, 직접 머지/배치하면 2~3배 효율. 방치 요소는 런 밖(오프라인 보상)에 집중.
4. **귀여운 동물 유닛**: 코어 유저 + 캐주얼 유저 모두 흡입.

## 2. 게임 흐름

### 2.1 단판(런) 흐름 (20~30분)

```
런 시작 (성벽 HP 풀, 기본 유닛 1~2개)
    │
    ▼
웨이브 1~5: 약한 적 소수. 골드 수집 → 유닛 구매/배치 학습
    │
    ▼
웨이브 6~15: 적 수/종류 증가. 머지로 유닛 강화 필요
    │            중간 보상 선택 (뱀서식 3택 1)
    ▼
웨이브 16~25: 다방향 러시. 유닛 재배치/머지 전략 중요
    │            미니보스 등장 (10웨이브마다)
    ▼
웨이브 26~35: 특수 적 등장 (비행, 방패, 속도). 빌드 전환 요구
    │
    ▼
웨이브 36+: 무한 스케일링. 언제까지 버틸 수 있나
    │
    ▼
성벽 파괴 = 런 종료
    │
    ▼
보상 정산: 별(메타화폐) + 도감 진행 + 업적
    │
    ▼
영구 강화 → 다음 런 시작 (더 강해진 상태)
```

### 2.2 메타 루프 (런 간 진행)

```
런 반복 → 별 축적 → 영구 업그레이드 구매 → 더 높은 웨이브 도달
    │
    ▼ (마일스톤 달성)
새 유닛 종류 해금
새 지역/테마 해금 (초원 → 숲 → 사막 → 설산 → 화산)
새 난이도 해금 (노말 → 하드 → 나이트메어)
    │
    ▼ (장기 진행)
초월(Ascension) → 소울 획득 → 초월 스킬트리 → 재성장
```

## 3. 핵심 시스템

### 3.1 성벽 시스템

- **성벽**: 화면 중앙에 고정된 방어 거점. HP를 가짐.
- **성벽 HP**: 런 시작 시 풀. 적이 성벽에 도달하면 HP 감소. 0이 되면 런 종료.
- **성벽 레벨**: 메타 진행으로 영구 강화 (HP 증가, 자동 회복, 방어력).
- **성벽 배치 슬롯**: 성벽 주변 8~12개 슬롯에 유닛 배치.

```
         [슬롯]  [슬롯]  [슬롯]
    [슬롯]                    [슬롯]
    [슬롯]    [ 성  벽 ]     [슬롯]
    [슬롯]                    [슬롯]
         [슬롯]  [슬롯]  [슬롯]

    ← 적    ↑ 적    → 적    ↓ 적
        (사방에서 웨이브)
```

### 3.2 유닛 시스템

#### 유닛 배치
- **구매**: 골드로 랜덤 유닛 뽑기 (상점에서 3택 1 or 랜덤 배치)
- **배치**: 빈 슬롯에 드래그 & 드롭
- **방향**: 각 슬롯은 자동으로 가장 가까운 적 공격 (사거리 내)

#### 머지 시스템
- **같은 유닛 3개 → 합치면 1레벨 업** (기차방어와 동일)
- 최대 레벨: 5 (Lv1~Lv5, 각 레벨마다 외형 변화)
- Lv5 1개 = 원본 81개 필요 (3^4). 실제로는 Lv3~4가 런 내 현실적 상한
- 머지 시 유닛 수 감소 → 적 스케일링 완화 (핵심 전략)

> **왜 3개 머지?** 2개 머지는 너무 빠르게 만렙 도달하거나, 만렙을 높이면 필요량이 기하급수적(2^6=64)이라 밸런스가 무너짐. 3개 머지는 "3번째를 모을 때의 긴장감"과 "머지 순간의 쾌감"이 검증된 구조.

#### 유닛 판매
- 슬롯이 꽉 찼을 때 불필요한 유닛을 **판매** 가능
- 판매 시 구매 비용의 **50%** 골드 환급
- 머지 재료가 안 맞을 때 슬롯을 비우는 전략적 선택

#### 유닛 종류 (초기 6종, 추후 확장)

| 유닛 | 타입 | 공격 | 특성 |
|------|------|------|------|
| 🐱 고양이 궁수 | 원거리 | 단일 타겟 | 기본 유닛. 빠른 공속 |
| 🐶 강아지 전사 | 근접 | 범위 | 성벽 앞에서 적 저지. 높은 체력 |
| 🐰 토끼 마법사 | 원거리 | 범위(스플래시) | 느리지만 광역. 밀집 적에 강함 |
| 🐻 곰 탱커 | 근접 | 단일 | 적 이동속도 감소. 높은 방어 |
| 🦊 여우 암살자 | 원거리 | 단일 | 높은 크리티컬. 보스에 강함 |
| 🐦 새 정찰병 | 원거리 | 관통 | 비행 적 공격 가능. 관통 화살 |

#### 유닛 진화 (머지 Lv5 도달 시)
- Lv5 유닛 + 특정 렐릭 보유 = **진화 유닛** (뱀서 무기 진화에서 착안)
- 예: 고양이 궁수 Lv5 + "화살비 렐릭" = **폭풍 궁수** (전체 화면 화살비)
- 진화 유닛은 Lv5보다 훨씬 강력하며, 슬롯 1개로 한 방향 완전 커버 가능

### 3.3 적 시스템

#### 적 스폰
- **4방향**에서 동시 스폰 (상하좌우)
- 웨이브마다 방향별 적 구성이 다름 → 유닛 재배치 유도
- 웨이브 번호에 비례해 수/HP/속도 스케일링

#### 적 종류

| 적 | 특성 | 대응 |
|----|------|------|
| 슬라임 | 기본. 느리고 약함 | 아무 유닛 |
| 고블린 | 빠름. 낮은 HP | 빠른 공속 유닛 |
| 오크 | 느림. 높은 HP | 고DPS 유닛 |
| 박쥐 (비행) | 지상 유닛 무시. 성벽 직행 | 새 정찰병 필수 |
| 방패병 | 전방 방어. 관통/범위만 유효 | 마법사/관통 유닛 |
| 폭탄 고블린 | 성벽 도달 시 대폭발 (고피해) | 우선 처치 필요 |
| 힐러 | 주변 적 치유 | 먼저 처치 |
| 보스 | 10웨이브마다. 높은 HP, 특수 패턴 | 전체 화력 집중 |

#### 적 스케일링 (핵심 밸런스)
```
적 HP   = baseHP * (1.08 ^ wave) * (1 + unitCount * 0.12)
적 수   = (baseCount + floor(wave * 0.8)) * (1 + unitCount * 0.04)
적 속도 = baseSpeed * (1 + unitCount * 0.02) * (1 + max(0, wave - 30) * 0.005)
```
- `unitCount * 0.12`: 유닛 8개 → 적 HP **x1.96** (거의 2배). 4개로 머지하면 **x1.48**. 차이가 체감됨
- `unitCount * 0.04`: 유닛 수에 따라 적 **수량**도 증가
- `unitCount * 0.02`: 유닛 수에 따라 적 **속도**도 증가
- 세 축 모두에 유닛 수 반영 → 머지의 전략적 가치가 명확

### 3.4 인런 경제

#### 골드 (인런 화폐, 매 런 리셋)
| 획득처 | 양 |
|--------|-----|
| 일반 적 처치 | 1~3 |
| 엘리트 적 | 5~10 |
| 보스 처치 | 30~50 |
| 웨이브 클리어 보너스 | wave * 2 |

| 사용처 | 비용 |
|--------|------|
| 유닛 뽑기 (랜덤 1종) | 10 + (보유유닛 수 * 3) |
| 유닛 재배치 | 무료 |
| 성벽 수리 (HP 20% 회복) | 50 * 사용횟수 |
| 상점 리롤 | 5 |

> **유닛 구매 비용 공식**: `10 + (currentUnitCount * 3)`
> 유닛이 많을수록 추가 구매 비용 증가 → 양보다 질 유도

#### 인런 보상 선택 (뱀서식)
- **5웨이브마다** 3택 1 보상 제시:
  - 유닛 강화: "모든 궁수 공격력 +20%"
  - 성벽 강화: "성벽 HP 15% 회복"
  - 특수 효과: "10초간 전체 슬로우"
  - 패시브 버프: "골드 획득 +30%", "공격속도 +15%"
- **보상 카드는 인런 스탯 버프만** (런 종료 시 리셋)
- 보상 풀은 현재 보유 유닛에 따라 가중치 조절 (궁수가 많으면 궁수 버프 확률↑)

> **카드 vs 렐릭 구분**: 카드 = 일시적 스탯 버프 (누적 가능). 렐릭 = 보스 드랍 전용, 고유 효과 + 진화 재료. 두 시스템이 역할이 겹치지 않음.

### 3.5 메타 진행 (런 간 영구 성장)

#### 별 (메타 화폐)
```
획득량 = floor(maxWave * 1.5) + bossKills * 10 + bonusMultiplier
```
- 높은 웨이브 = 더 많은 별
- 보스 처치 보너스
- 보상형 광고로 x2 가능

#### 영구 업그레이드 (별로 구매) — 16종

| 카테고리 | 업그레이드 | 최대Lv | 효과 |
|---------|----------|--------|------|
| **성벽** | 성벽 체력 | 30 | +5% HP/Lv |
| | 자동 회복 | 20 | +0.5 HP/초/Lv |
| | 방어력 | 20 | -2% 피해/Lv |
| **유닛** | 기본 공격력 | 30 | +3% ATK/Lv |
| | 공격 속도 | 25 | +2% ASPD/Lv |
| | 시작 유닛 | 5 | 런 시작 시 무료 유닛 +1/Lv |
| **경제** | 골드 획득량 | 30 | +5% 골드/Lv |
| | 유닛 할인 | 20 | -2% 유닛 비용/Lv |
| | 별 보너스 | 20 | +5% 별 획득/Lv |
| **특수** | 슬롯 확장 | 8 | 배치 슬롯 +1/Lv (기본 8) |
| | 유물 행운 | 10 | +5% 렐릭 등장률/Lv |
| **Phase 4** | 초기 자금 | 10 | 런 시작 골드 +20/Lv |
| | 유물 품질 | 10 | 고등급 유물 확률 +3%/Lv |
| | 콤보 지속 | 10 | 콤보 유지 시간 +0.3초/Lv |
| | 하이브리드 강화 | 10 | 하이브리드 유닛 ATK +5%/Lv |
| | 기본 크리티컬 | 10 | 기본 크리 확률 +2%/Lv |

#### 비용 공식
```
upgradeCost(lv) = baseCost * (1.12 ^ lv)
```
- 레벨당 12% 증가 (기존 프로젝트의 15%보다 완만 → 꾸준한 성장감)

### 3.6 초월 시스템 (장기 진행)

- **조건**: 누적 별 N개 이상 도달
- **효과**: 모든 영구 업그레이드 리셋 → **소울** 획득
- **소울 업그레이드**: 초월 전용 스킬트리
  - 시작 골드 보너스
  - 유닛 머지 시 추가 보너스
  - 새 유닛 타입 해금
  - 난이도 해금 (하드, 나이트메어)
  - 자동 머지 (방치 편의)
  - 자동 배치 (방치 편의)

```
초월 임계값 = 5000 * (3 ^ ascensionCount)
소울 획득량 = floor(sqrt(totalStars / 100))
```

### 3.7 유물(렐릭) 시스템 — 50개, 5단계 희귀도

- **획득**: 보스 처치 시 **전용 드랍** (런 내 한정, 카드와 별개)
- **효과**: 스탯 버프(일반) → 메카닉 변형(레어) → 규칙 변경(에픽) → 런 정의 변경(전설/신화)
- **진화 재료**: 특정 진화석 렐릭 + Lv5 유닛 = 진화
- **최대 보유**: 런당 **5개** (무한의 돌 유물 시 7개)
- **드롭 선택**: 3택 1 (가중 랜덤, `relicQualityBonus` 업그레이드로 고등급 확률↑)
- **데이터/로직 분리**: `relic_data.dart` (정의) + `relic_manager.dart` (효과)

| 등급 | 수량 | 가중치 | 대표 유물 |
|------|------|--------|----------|
| 일반 | 15개 | 40 | ATK+15%, 공속+15%, 골드+30%, 크리+10%, 가시갑옷, 처치회복 |
| 레어 | 15개 | 30 | 분열탄, 연쇄번개, 광전사, 관통강화, 도박사, 쌍둥이, 거인, 소형화 |
| 에픽 | 12+8개 | 20 | 살아있는 성벽, 시간왜곡, 폭발머지, 도플갱어, 보물사냥꾼 + 진화석 8개 |
| 전설 | 6개 | 8 | 불사조(부활), 차원균열(무료유닛), 마이다스(ATK→골드), 전쟁의신(ATKx3) |
| 신화 | 2개 | 2 | 카오스(랜덤효과), 역전의법칙(저HP→고ATK) |

### 3.7.1 이종 머지 시스템 (Cross-Breed)

> **핵심 차별점**: 다른 종류의 유닛 2마리를 합성하여 하이브리드 유닛 생성

- **조건**: 다른 종 2마리, 둘 다 **Lv3 이상**
- **결과**: 양쪽 부모의 능력을 결합한 **하이브리드 유닛** 탄생
- **12종 레시피** 구현 (8종 기본 유닛 조합)
- **영구 업그레이드**: `hybridBonus`로 하이브리드 전용 ATK 보너스

| 조합 | 하이브리드 | 특수 능력 |
|------|-----------|----------|
| 🐱+🦊 | 불꽃 사냥꾼 🔥 | 크리 20% + 관통 |
| 🐶+🐻 | 철벽 전사 🛡️ | 근접 광역 + 슬로우 |
| 🐰+🦉 | 대마법사 🌟 | 초대형 스플래시 + 장거리 |

### 3.7.2 콤보 시스템

- **연속 처치** (2초 이내) → 콤보 카운트 증가
- **5단계 티어**: NICE(5+) → GREAT(10+) → AMAZING(25+) → UNSTOPPABLE(50+) → GODLIKE(100+)
- **보너스**: 10콤보마다 골드 보너스, 파티클 이펙트 크기 x1.2~x3.0 증폭
- **시각 피드백**: HUD에 콤보 카운터 + 티어별 색상 + 티어 변경 시 화면 플래시
- **영구 업그레이드**: `comboDuration`으로 콤보 유지 시간 연장 (+0.3초/Lv)

### 3.8 웨이브 보상 선택 시스템 (뱀서식 레벨업)

5웨이브마다 **3택 1** 보상 카드 (인런 스탯 버프, 누적 가능):

**카드 등급**:
| 등급 | 확률 | 예시 |
|------|------|------|
| 일반 (회색) | 60% | 공격력 +10%, HP 회복 5%, 골드 +15% |
| 레어 (파랑) | 25% | 특정 유닛 공속 +30%, 성벽 방어 +20% |
| 에픽 (보라) | 12% | 전체 유닛 공격력 +25%, 성벽 자동회복 |
| 전설 (금) | 3% | 성벽 무적 10초, 전체 적 50% HP 감소 |

> **카드 = 스탯 버프**. 렐릭은 보스에서만 드랍되며 카드로 획득 불가.

### 3.9 반방치 시스템

> **포지셔닝**: "방치형"이 아니라 **"반방치형"**. 런 중에는 적극 플레이가 기본이지만, 잠시 손 놓아도 바로 죽지 않음. 방치 요소는 **런 밖**(오프라인 보상)에 집중.

| 상태 | 판정 | 효과 |
|------|------|------|
| 적극 플레이 | 10초 내 터치 | 정상 플레이. 머지/배치/판매 직접 조작 |
| 잠시 방치 | 10초 이상 무입력 | 기본 자동 배치 작동 (빈 슬롯에 랜덤 유닛). 효율 60% |
| 오프라인 | 앱 종료 | 런 일시정지 (진행 안 됨). 별도 오프라인 별 축적 (최대 12시간) |

**자동 시스템 (처음부터 제공)**:
- **기본 자동 배치**: 잠시 방치 시 빈 슬롯에 랜덤 유닛 자동 배치. 단, 머지는 안 함 → 유닛 수만 늘어남 → 적도 강해짐 → **직접 플레이의 가치 유지**

**자동 시스템 (초월 해금)**:
- **자동 머지**: 3초마다 머지 가능한 유닛 자동 머지 (방치 효율 크게 상승)
- **자동 판매**: 슬롯이 꽉 찼을 때 가장 낮은 레벨 유닛 자동 판매
- **스마트 배치**: 빈 슬롯에 가장 필요한 유닛 타입 우선 배치

## 4. 밸런스 설계

### 4.1 웨이브 스케일링

```dart
// 적 HP 스케일링
enemyHP(wave) = baseHP * pow(1.08, wave) * (1 + unitCount * 0.12)

// 적 수 스케일링
enemyCount(wave) = (baseCount + (wave * 0.8).floor()) * (1 + unitCount * 0.04)

// 적 속도
enemySpeed(wave) = baseSpeed * (1 + unitCount * 0.02) * (1 + max(0, wave - 30) * 0.005)

// 보스 HP (10웨이브마다)
bossHP(wave) = 100 * pow(1.15, wave) * (1 + unitCount * 0.08)
```

**유닛 수에 따른 스케일링 체감표**:
| 유닛 수 | 적 HP 배율 | 적 수 배율 | 적 속도 배율 | 총 압력 |
|---------|-----------|-----------|------------|---------|
| 3개 | x1.36 | x1.12 | x1.06 | 낮음 |
| 6개 | x1.72 | x1.24 | x1.12 | 중간 |
| 8개 | x1.96 | x1.32 | x1.16 | 높음 |
| 12개 | x2.44 | x1.48 | x1.24 | 극한 |

### 4.2 유닛 DPS 공식

```dart
unitDPS(level) = baseATK * pow(2.0, level - 1) * upgradeMultiplier
```
- 머지 1회 = DPS 2배 (3유닛 → 1유닛, 총 DPS: base*3 → base*2 = 67%)
- **9유닛 → Lv3 1개**: DPS = base * 4 (9유닛 DPS base*9 대비 44%)
- **핵심**: 순수 DPS만 보면 머지가 손해. 하지만 **적 스케일링 감소**(HP/수/속도 3축)가 크기 때문에 머지가 유리
- 레벨당 2배 성장은 "머지했을 때 확실히 강해졌다"는 쾌감 보장

### 4.3 경제 밸런스

```
웨이브당 평균 골드 수입 = (적수 * 평균드랍) + 웨이브보너스
유닛 구매 간격 목표: 2~3 웨이브마다 1회
머지 가능 시점: 6~9 웨이브 (같은 유닛 3개 모을 때까지)
```

| 웨이브 | 예상 유닛 수 | 예상 최고 레벨 | 상태 |
|--------|------------|-------------|------|
| 1~5 | 2~4 | Lv1 | 생존 학습 |
| 6~10 | 4~6 | Lv1~2 | 첫 머지 경험 |
| 11~20 | 5~7 | Lv2~3 | 빌드 구축 |
| 21~30 | 5~8 | Lv3~4 | 파워 스파이럴 |
| 31~40 | 5~8 | Lv4 | 최적화 |
| 41+ | 4~6 | Lv4~5 | 진화 유닛 등장 (Lv5 렐릭 조합) |

### 4.4 파워 스파이럴 (뱀서에서 가져온 핵심)

```
웨이브 1~10:  긴장. 적 하나하나가 위협. 생존에 집중
웨이브 11~20: 성장. 머지로 강해지는 쾌감. "강해지고 있다"
웨이브 21~30: 파워 판타지. 적이 녹음. 화면 가득 이펙트
웨이브 31+:   재긴장. 스케일링이 따라옴. 전략 최적화 필요
웨이브 40+:   한계 도전. 어디까지 갈 수 있나
```

## 8. 저장 시스템

### 저장 데이터

```dart
// 메타 (영구) — defense_save_manager.dart
- stars: int              // 별 (메타 화폐)
- souls: int              // 소울 (초월 화폐)
- highestWave: int        // 최고 웨이브 기록
- totalKills: int         // 누적 킬 수
- totalRuns: int          // 총 런 횟수
- totalMerges: int        // 총 머지 횟수
- totalStarsEarned: int   // 총 별 획득량
- totalBossKills: int     // 총 보스 킬 수
- upgrades: Map<String, int>  // 영구 업그레이드 16종 레벨
- lastOnline: String      // 마지막 접속 시간 (ISO 8601)

// 인런 (중간 저장) — JSON 직렬화
- currentWave: int
- wallHP: double
- gold: int
- kills: int
- relics: List<String>        // 보유 렐릭 ID 목록
- unitSlots: List<{typeId, level, isEvolved}>  // 배치된 유닛
- rewardMultiplier: double     // 보상 배율
- waveManager: Map             // 웨이브 매니저 전체 상태
```

### 저장 방식 (구현 완료)
- `SharedPreferences` — 메타 데이터 개별 키, 인런 데이터 JSON 문자열
- **중간 저장 트리거**: 앱 백그라운드 진입 시 (`didChangeAppLifecycleState`)
- **복원**: 메인 메뉴 "이어하기" → `resumeRun()` → 상태 복원 + 현재 웨이브 재시작
- **삭제 트리거**: 런 종료(`onWallDestroyed`) 또는 새 게임 시작(`startGame`)
- 메타 저장: 런 종료/업그레이드 구매 시 `saveAll()` 호출

## 11. 화면 방향

**결정: Portrait (세로)**

- 성벽이 화면 중앙, 하단 1/4에 유닛 상점 UI, 상단에 HUD
- 한 손으로 유닛 드래그 & 머지 가능
- 모바일 게임의 기본 자세 (세로 파지)
- 전장이 정사각형에 가까워서 사방 방어 균형 맞음

```
┌──────────────┐
│  [HUD 영역]   │  ← 웨이브, 골드, 성벽HP
│              │
│   적↓        │
│ 적→ [성벽] ←적│  ← 게임 필드 (정사각형)
│   적↑        │
│              │
├──────────────┤
│ [유닛 상점]   │  ← 뽑기, 보유 유닛, 판매
└──────────────┘
```
